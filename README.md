# Apple Store Demo

A premium React + Vite storefront inspired by Apple product pages and modern e-commerce UI.

## Features

- Responsive product catalog
- Shopping cart and wishlist
- Product detail pages
- Search and category browsing
- Support pages for shipping, returns, and contact
- Premium Apple-inspired design and animations
- Mobile-friendly layout

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- React Icons

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

### 3. Build for production

```bash
npm run build
```

### 4. Preview the production build

```bash
npm run preview
```
